## 2. 浏览器为什么使用 Edge

Playwright 支持通过 `PLAYWRIGHT_BROWSERS_PATH` 将 Chromium 下载到 E 盘。此前已尝试安装到 E 盘的项目验证目录，但安装停滞，未成功形成可用浏览器。因此按用户要求使用本机 Edge，已实际完成页面操作、截图、Trace 采集和离线报告验证。

这是安装未成功后的回退选择，不能据此断言 E 盘不支持安装浏览器。当前没有额外安装 Edge，没有更改系统默认浏览器，也没有把浏览器下载到 C 盘。

当前配置：

```yaml
execution:
  browser: msedge
  headless: true
  timeout_ms: 15000
  retries: 0
```

`framework/browser.py` 依次检查系统级 32 位程序目录、系统级程序目录和用户级 Edge 安装位置，并把真实路径交给 Playwright。这样可以兼容当前机器上系统级安装的 Edge。

## 3. 以后安装 Chromium 到 E 盘

在项目目录运行：

```powershell
Set-Location E:\test-projectA\web
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-browser.ps1
```

脚本将浏览器安装到：

```text
E:\test-projectA\web\.browsers
```

只有脚本明确提示安装成功后，再把 YAML 的 `browser: msedge` 改为 `browser: chromium`。如果下载失败，保持 msedge 即可。接口测试不使用浏览器夹具时，不需要额外安装 Chromium。

手动安装的等价命令：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = 'E:\test-projectA\web\.browsers'
.\.venv\Scripts\python.exe -m playwright install chromium
```

浏览器修订版本和 Playwright 版本相对应，升级 Python 包后应重新运行浏览器安装并验证。`.browsers` 不应提交至 Git。

## 4. Windows 脚本编码

项目的 `run.ps1` 和 `install-browser.ps1` 使用 UTF-8 BOM，兼容 Windows PowerShell 5 对中文脚本的读取。中文 Markdown、Python 和报告使用 UTF-8。已经实测 Windows PowerShell 包装入口能转交参数，并保留退出码 0 和 5。

## 5. 安装排错记录

前轮曾遇到 pip 用户缓存目录写入停滞、工具目录权限刷新失败和执行账户锁定。本轮已恢复权限，在最终目标目录完成安装。安装时临时目录限定在项目 `.runtime/tmp`，使用已经校验的依赖安装包完成离线安装。开发下载缓存会在交付前删除，锁定版本文件保留，后续重装可按 README 联网下载。

这些开发工具故障不需要通过降低被测系统权限、修改业务代码或关闭系统安全功能处理。
